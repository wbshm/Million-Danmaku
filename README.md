# 百万弹幕

发布在 B 站 Toy 平台的像素风肉鸽。你是一个 0 粉的小 UP 主，在飞来的弹幕里活下来，把弹幕打成粉丝，一局约 5 分钟，目标是涨到 100 万粉。

- 游戏区固定 216×432（竖屏），手机和电脑上的玩法完全一样；电脑宽屏时两侧多出信息面板。
- 敌人就是弹幕文字：滚动、彩色、逆向、顶部/底部固定、大字精英、刷屏墙，第 5 波和第 10 波有 Boss。
- 两层构筑：捡经验升级三选一（16 种基础武器、8 种合成武器、7 种被动）；每波结束进商店买遗物（22 种，分加法、乘法、功能）。
- 6 种「机制武器」不靠定时开火：点名弹幕里的关键字、把弹幕洗白成友军、把弹幕剪成单字、放置顶牌挡路、站住蓄力、擦弹反击。
- 擦弹：贴着弹幕或敌方子弹掠过而不被打中，给专属技能充能并续上连击。
- 科技树：每局结算得「灵感」，在标题页的科技树里换永久加成（3 条线，15 个节点）。
- 武器合成：一对配方里的两把武器都升到 Lv4，升级时会出现合成卡，两把合成一把更强的，并空出一个武器栏。
- 每个角色有一个专属技能（大招）：杀敌充能，充满后点右下角按钮或按空格释放。
- 7 个角色：5 个按最高分解锁，2 个关注 UP 主解锁。给 UP 主的视频点赞、投币、收藏还有开局福利。
- 计分：每次击杀 `涨粉 = (基础值 + 加值) × 倍率`，`倍率 = (1 + 加法项之和) × 乘法项之积 × 连击加成`。

## 操作

| 操作 | 手机 | 电脑 |
|---|---|---|
| 移动 | 在屏幕任意位置拖动 | WASD 或方向键 |
| 攻击 | 自动 | 自动 |
| 专属技能 | 点右下角的技能按钮 | 空格 |
| 选升级 | 点卡片 | 点卡片，或数字键 1 / 2 / 3；`R` 换一批（需要科技树「选题会」） |
| 科技树 | 标题页或结算页点「科技树」 | 同左，或按 `T` |
| 商店 | 点价格按钮购买 | 同左；`R` 刷新，`Enter` 下一波 |
| 暂停 | 右上角暂停键 | `Esc` 或 `P` |

切到后台会自动暂停。电脑上另有 `M` 开关音乐、`F` 全屏、`Q` / `E` 切换角色，鼠标悬停按钮会高亮。

## 发布前要填的配置

打开 [src/config.ts](src/config.ts)：

- `videoBvid`：你的一个视频的 BV 号。玩家给它点赞 / 投币 / 收藏能拿福利，「去关注」「去三连」按钮也跳到它。**留空则三连福利面板不显示。** SDK 只能查本 Toy 作者自己的视频（含联合投稿），填别人的视频查不到。
- `authorMid`：你的 UID，可选。只在没填 `videoBvid` 时用，「去关注」会跳到你的空间。

## 角色

| 角色 | 起手 | 特点 | 专属技能 | 解锁条件 |
|---|---|---|---|---|
| 萌新UP | 点赞 | 3 点生命 | 求三连：6 秒内所有武器攻速翻倍 | 默认 |
| 硬币富翁 | 投币 | 自带 15 硬币 | 撒币：向 10 个弹幕扔硬币炸弹，并得 5 硬币 | 最高分 1 万 |
| 铁粉 | 洗白 + 收藏 | 拾取范围 +50% | 粉丝护体：4 秒无敌，并吸来全场掉落 | **关注 UP 主** |
| 充电大佬 | 充电 | 每波多得 4 硬币 | 满电：闪电劈中屏幕上每一个弹幕 | **关注 UP 主** |
| 三连仙人 | 一键三连 | 倍率 +0.5，仅 2 点生命 | 三连暴击：8 秒内涨粉翻倍 | 最高分 10 万 |
| 转发达人 | 转发 + 极限走位 | 移速 +15%，倍率 +0.3 | 上热搜：清空敌方子弹，全场弹幕定身 4 秒 | 最高分 30 万 |
| 百大UP | 点赞 + 一键三连 | 起手就是一对合成配方 | 百大光环：冲击波重创全屏弹幕，敌方子弹变经验 | 最高分 100 万 |

专属技能第一次需要 40 点充能（普通弹幕 1 点，大字弹幕和 Boss 5 点，每次擦弹 0.5 点），每用一次多 12 点，最多 90 点。

关注专属角色只认「当前是否关注」：取关后会重新锁上。查不到状态时（未登录、不在 B 站内）沿用上次存下来的结果。

## 武器与合成

基础武器 16 种（最高 Lv5），最多同时带 4 种。先是 10 种定时开火的常规武器：

| 武器 | 效果 |
|---|---|
| 点赞 | 向最近的弹幕直射，高等级可穿透 |
| 一键三连 | 朝目标扇形连发三枚 |
| 投币 | 抛出硬币，落地范围爆炸 |
| 充电 | 闪电随机劈中屏幕上的弹幕 |
| 收藏 | 星星环绕自身，碰到就伤害 |
| 转发 | 命中后在弹幕之间弹射 |
| 举报 | 横扫自己所在的一整行 |
| 屏蔽 | 身边一圈持续伤害，Lv3 起减速 |
| 应援 | 应援灯牌跟着你，自动射击 |
| 拖进度条 | 飞出去再飞回来，沿途全部穿透 |

再是 6 种机制武器，各自挂在一件别的事情上（升级卡片上标着「机制武器」）：

| 武器 | 靠什么触发 | 效果 |
|---|---|---|
| 关键词 | 弹幕的文字 | 找出满屏弹幕里出现最多的那个字，带这个字的弹幕全部受伤并被划线；Lv3 起减速，Lv5 一次点两个字 |
| 洗白 | 击败 | 被它打败的弹幕变成绿色的「粉丝弹幕」，掉头沿原来那一行冲回去撞同行，路上还替你挡子弹（Boss 不会被洗白） |
| 鬼畜 | 击杀数 | 每打败 4 个弹幕（升级后 3 个、2 个），把最后那条剪成单字四散飞射，字打死的也算数，能连锁 |
| 置顶 | 站位 | 在面朝方向的身前放一块置顶牌：这一行的弹幕过不去，贴着它的持续掉血，子弹也被挡住 |
| 憋大招 | 站着不动 | 不动时蓄力，最多三段；一动就放出冲击波，段数越多范围和伤害越大，蓄满自动释放且威力 +50% |
| 极限走位 | 擦弹 | 每次擦弹向附近弹幕射出反击镖，并加大擦弹判定范围 |

合成武器 8 种（最高 Lv3）。配方里两把武器都到 Lv4 后，升级时必定出现合成卡：

| 配方 | 合成结果 | 效果 |
|---|---|---|
| 点赞 + 一键三连 | 弹幕风暴 | 七向穿透弹幕，高速连发 |
| 投币 + 充电 | 氪金雷暴 | 多道落雷，每道都会大范围爆炸 |
| 收藏 + 转发 | 星链 | 五颗星星大圈环绕，并不断射出弹射星 |
| 举报 + 屏蔽 | 小黑屋 | 大范围减速力场，并同时横扫三行 |
| 应援 + 拖进度条 | 应援团 | 三块灯牌一起扔回旋进度条 |
| 关键词 + 洗白 | 控评 | 一次点名两个关键字并减速，被打败的全部倒戈成粉丝弹幕 |
| 鬼畜 + 极限走位 | 名场面 | 每次擦弹都把那条弹幕炸成单字，每打败两个弹幕再炸一次 |
| 置顶 + 憋大招 | 镇站之宝 | 同时放三块置顶牌，每块都不断放出冲击波 |

已经拿到配方里的一把时，另一把在升级选项里出现的概率是平时的 3 倍。升级卡片上会写着这把武器能和谁合成；暂停菜单（电脑版在右侧面板）能看全部配方和当前进度。

## 擦弹

离弹幕文字或敌方子弹不超过 5 像素、又没被打中，算一次擦弹：

- 专属技能充能 +0.5；
- 连击计时重置（连击不会断）；
- 带着「极限走位」或「名场面」时触发它们的反击。

同一条弹幕 1.2 秒内只算一次，同一颗子弹只算一次，受伤后的无敌时间里不算。

## 科技树

每局结算（不管输赢）都会得到「灵感」：基础 2 点，每打完一波 +1，每击败一个 Boss +2，再按本局涨粉加 0～12 点（1 千 / 1 万 / 10 万 / 30 万 / 100 万 / 500 万各一档）。新手一局大约 5～8 点，打通并过百万约 25 点。

灵感在标题页或结算页的「科技树」里花。三条线各 5 个节点，要先点亮上一个才能点下一个；全部点满需要 321 灵感。

| 线 | 节点（从上到下） |
|---|---|
| 内容 | 剪辑功底：伤害 +4% ×3 → 稳定更新：攻击间隔 -3% ×3 → 爆款体质：暴击率 +3% ×3 → 选题会：每局升级时可「换一批」×2 → 独家秘方：合成只需 Lv3 |
| 运营 | 启动资金：开局硬币 +2 ×3 → 长期商单：每波多 1 硬币 ×3 → 粉丝基础：开局倍率 +0.1 ×3 → 砍价：商店价格 -5% ×2 → 流量密码：涨粉基础值 +1 |
| 体质 | 手速：移速 +3% ×3 → 路人缘：拾取范围 +12% ×3 → 擦弹大师：擦弹范围 +1、充能 +50% ×3 → 熬夜冠军：生命上限 +1 → 开场高能：开局专属技能充满 |

存档里只记「累计获得的灵感」和各节点等级，可花的数量是算出来的（累计 − 已点节点的花费），所以本地和云端存档合并时不会凭空多出灵感。在科技树里买东西先写本地，离开科技树界面时才写一次云存储。

## 三连福利

| 对配置的视频 | 开局福利 |
|---|---|
| 点赞 | 生命上限 +1 |
| 投币 | 开局 +10 硬币 |
| 收藏 | 每次商店免费刷新 1 次 |
| 三项全做 | 额外倍率 +0.3 |

玩家点「去给视频三连」跳到视频，回到游戏时自动重新查询；也可以手动点「刷新状态」（5 秒冷却）。

## 电脑版布局

窗口宽高比 ≥ 1.05 时自动切到宽屏布局，游戏区不变，两侧各加一块面板（每块 110–280 像素，16:9 的窗口正好铺满）：

- 左侧：对局中显示当前倍率的加法 / 乘法 / 连击拆解、武器、被动、遗物；菜单里显示玩法说明。
- 右侧：按键说明；对局中另有波次、剩余时间等数据；菜单里显示本周排行（启动时拉一次）。

如果 B 站网页端把 Toy 放在竖长的容器里，会自动保持竖屏布局。

## 开发

需要 Node.js 22（Vite 6 不支持 Node 16）。本机用 fnm 的话先 `fnm use 22`。

```sh
npm install
npm run dev      # 本地开发，默认 http://127.0.0.1:5173
npm test         # 单元测试
npm run sim      # 无头模拟 200 局 × 每种打法，看分数分布
npm run build    # 类型检查 + 构建 + 生成单文件
```

开发模式下可以加这些 URL 参数（生产构建里不存在）：

- `?mocktoy=1`：注入一个假的 `window.toy`，可以走通存档、提交分数、排行榜、二维码。调用记录在 `window.__toyLog`。
- `?mocktoy=limit`：第一次写云存档返回限流错误 307044，用来验证退避重试。
- `?mocktoy=app`：模拟 App 内环境（支持 `share`）。
- `?mocktoy=fan`：一开始就是「已关注 + 已三连」。其他 mock 模式下，第一次点「去关注 / 去三连」后才变成已关注已三连。
- `?bv=BVxxxx`：临时指定视频 BV 号（mock 模式下不填会自动用一个假的）。
- `?bot=1`：自动走位；`?speed=6`：六倍速。

## 构建产物与上传

`npm run build` 生成两种形态，内容相同：

- `dist/`：`index.html` + `assets/`（JS 约 60 KB，字体约 690 KB）。
- `play.html`（项目根目录和 `dist/` 里各一份）：把 JS、CSS、字体都内联进去的单文件，约 960 KB。

SDK 文档没有写 Toy 后台接受的上传格式和包体上限，所以两种都给。**如果后台只收单个 HTML，请把 `play.html` 改名为 `index.html` 再传**，因为分享链接固定指向 `index.html?s=分数`。

两种形态都保留了 `<script src="//s1.hdslb.com/bfs/seed/toy/app/sdk/toy-sdk.js">` 外链，由平台提供。

## 平台接入

所有 SDK 调用都在 [src/platform/toy.ts](src/platform/toy.ts)。

| 时机 | 调用 |
|---|---|
| 启动 | `getCloudStorage(['save_v1'])` 一次（后台进行，不阻塞标题界面）；`onContainerChange` 适配安全区；`getAuthorProfile`、`getAuthorRelation`、`getVideoUserActions` 各一次 |
| 点「去关注 / 去三连」 | `navigate({type:'video', id: BV号})`（在点击事件里同步调用）；回到页面后重新查一次关注和三连状态 |
| 离开科技树 | 这次进来买过东西的话，`setCloudStorage({save_v1})` 一次 |
| 结算 | `setCloudStorage({save_v1})` 一次；`submitScore` 榜 1 = 本局涨粉；达成百万时再提交榜 2 = 达成时剩余秒数 |
| 排行榜界面 | `getRankList` + `getMyRank`，按「榜位 + 周期」缓存，只有点「刷新」才重新拉（5 秒冷却） |
| 分享按钮 | App 内 `share({path:'index.html?s=分数'})`；Web 端 `getQrCode` 显示二维码 |

几条约束：

- 存档只占一个 key `save_v1`，实际不到 250 字节（上限 1024）。
- 分数提交前截断到 0 ~ 16,777,215。
- 限流错误（`http_error` / 307044）按 0.8 秒、1.6 秒退避重试，最多 3 次；其他错误不重试。
- 每个调用都有超时。在 B 站之外打开时，真 SDK 的 `isSupport` 会返回 `true`，但调用永远不返回，所以超时是必须的；此时游戏退回 localStorage，照常可玩。
- 弹幕文案全部内置，不接收玩家输入，所以没用 `checkInputSafety`。

**本地验证不了的部分**：真实 SDK 在 B 站 App / Web 里的表现（登录态、分享面板、安全区、排行榜真实数据）。上传后请在 App 里完整打一局确认。

## 数值

都在 [src/game/balance.ts](src/game/balance.ts)（波次曲线）、[weapons.ts](src/game/weapons.ts)、[relics.ts](src/game/relics.ts)。科技树在 [tech.ts](src/game/tech.ts)。改完跑 `npm run sim` 看分布（`npm run sim -- 100 max` 是点满科技树的情况）。当前版本的模拟结果，科技树一格没点：

| 角色 | 随机选：中位数 | 随机选：过百万 | 冲合成和乘法遗物：中位数 | 冲合成和乘法遗物：过百万 |
|---|---|---|---|---|
| 萌新UP | 2.2 万 | 1% | 71 万 | 37% |
| 硬币富翁 | 2.6 万 | 3% | 62 万 | 31% |
| 铁粉 | 3.8 万 | 1% | 24 万 | 9% |
| 充电大佬 | 7.4 万 | 1% | 82 万 | 40% |
| 三连仙人 | 1.1 万 | 0% | 55 万 | 27% |
| 转发达人 | 1.7 万 | 0% | 3 万 | 0% |
| 百大UP | 15.1 万 | 5% | 108 万 | 57% |

每格 100 局，不含三连福利。最高一局约 810 万，没有任何一局碰到排行榜上限。

科技树点满之后，同样的两种打法：随机选的过百万率是 3%～20%（百大UP 46%），会玩的打法是 37%～90%（百大UP 98%）。会玩的打法里约 1% 的局会超过排行榜上限 1677 万，提交时按上限截断。

模拟的局限，上线后要按真实数据再调：

- 机器人躲弹幕比真人准，真人的存活率会更低。
- 机器人离弹幕远远的，一局只擦弹几次，也不会故意站住蓄力。所以「极限走位」「名场面」「憋大招」在模拟里几乎没发挥，起手带「极限走位」的「转发达人」数字因此很难看，真人手里的强度需要实测。
- 「铁粉」起手换成了「洗白 + 收藏」，模拟里偏弱，同样需要实测。
